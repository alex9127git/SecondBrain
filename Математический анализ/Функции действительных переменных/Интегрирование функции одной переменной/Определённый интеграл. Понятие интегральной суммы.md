## Основные определения
Пусть [[Понятие функции#Определение|функция]] $y = f(x)$ определена на отрезке $[a; b]$. Пусть на этом отрезке произвольным образом заданы точки $x _0, x _1, x _2, \dots, x _n$ так, что:

$$
x_0 = a\qquad x_n = b\qquad a < x_1 < x_2 < \cdots < x_{n-1} < b
$$

Определённый выбор точек $x_1, x_2, \dots, x_{n-1}$ называют разбиением сегмента $[a; b]$, сами точки называют точками разбиения, а сегменты $[x _{i - 1}, x _{i}]$ называют частичными сегментами.

$\Delta x _i = x _i - x _{i-1}$ — длина $i$-го частичного сегмента.

На каждом частичном сегменте произвольным образом выберем точку $\xi _i \in (x _{i-1}, x_i)$ — промежуточную точку частичного сегмента.

Составим сумму вида

$$
I(x_i, \xi_i) = \sum_{i=1}^{n} f(\xi_i)\Delta x_i
$$

Эта сумма называется интегральной суммой функции $y = f(x)$, соответствующей данному разбиению сегмента $[a; b]$ и данному выбору промежуточных точек на частичных сегментах.

Геометрически интегральная сумма представляет собой сумму площадей прямоугольников, у которых одна сторона равна $\Delta x _i$, а вторая сторона равна $f(\xi _i)$.
## Определение определённого интеграла
Введём обозначение $\Delta = \max_{1 \le i \le n} \Delta x_i$. $\Delta$ будем называть диаметром разбиения.

Число $I$ называют [[Предел функции#Определение по Коши (на языке ε — δ)|пределом]] интегральных сумм $I(x _i, \xi _i)$ при $\Delta \rightarrow 0$. если:

$$
\forall \varepsilon > 0 : \exists \delta = \delta(\varepsilon) : \forall x_i, \xi_i, \Delta < \delta, |I-I(x_i, \xi_i)| < \varepsilon
$$

то есть для любого выбора промежуточных точек $\xi _i$ и для любого разбиения сегмента $[a; b]$ где диаметр разбиения $\Delta < \delta$, число $I$ ненамного отличается от значения интегральной суммы.

Данное выражение можно записать по другому:

$$
I = \lim_{\Delta \rightarrow 0} I(x_i, \xi_i)
$$

Если этот предел существует, то число $I$ называют определённым интегралом от функции $f(x)$ на промежутке $[a; b]$. Саму функцию называют интегрируемой по Риману, а определённый интеграл записывается следующим образом:

$$
I = \int_a^b f(x)\ \mathrm{d}x
$$
### Физические примеры
- путь, пройденный материальной точкой по прямой со скоростью $v(t)$ за промежуток времени $[t _1, t _2]$ может быть вычислен с помощью определённого интеграла $S = \int _{t _1} ^{t _2} v(t)\ \mathrm{d}t$;
- работа силы $f(x)$ по перемещению материальной точки из точки $a$ в точку $b$. Направление силы совпадает с направлением оси $Ox$, если $f(x) > 0$. и противоположно направлению оси $Ox$. если $f(x) < 0$: $A = \int _{a} ^{b} f(x)\ \mathrm{d}x$.
## Интегрирование постоянных функций
Проверим определение определённого интеграла для функции $f(x) = C$ и убедимся, что предел существует. Составим интегральную сумму

$$
I(x_i, \xi_i) = \sum_{i=1}^n f(\xi_i) \Delta x_i = \sum_{i=1}^n C\Delta x_i = C \sum_{i=1}^n \Delta x_i = C(b - a)
$$

Рассмотрим функцию Дирихле:

$$
D(x) = \begin{cases}
1, \text{если }x \in \mathbb{Q}\\
0, \text{если }x \in \mathbb{I}
\end{cases}
$$

В данном случае интегральные суммы зависят от выбора промежуточных точек и от разбиения отрезка $[a; b]$. Если в качестве промежуточных точек выбрать только рациональные значения, то значение интегральной суммы будет равно $b - a$. Если в качестве промежуточных точек выбрать только иррациональные значения, то интегральная сумма равна нулю. В случае частичного совпадения с рациональными и иррациональными числами значение интегральной суммы будет варьироваться от $0$ до $b - a$. Это означает, что не существует конечного предела интегральных сумм, и функция Дирихле не интегрируема по Риману.

Позднее мы докажем, что все непрерывные функции и часть разрывных функций интегрируемы по Риману. Для этого необходимо развить теорию сумм Дарбу.
