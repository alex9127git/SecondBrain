## Остаток ряда. Определения
Если в исходном [[Числовые ряды. Основные определения#Определения|числовом ряду]] отбросить первые $m$ членов, то получится новый ряд

$$
a_{m+1} + a_{m+2} + \cdots + a_{m+k} + \cdots = \sum_{k=m+1}^\infty
$$

Этот ряд называется остатком исходного ряда после $m$-го члена.
## Теорема о сходимости остатков рядов (№69)
**Если [[Числовые ряды. Основные определения#Сходимость числового ряда|сходится]] исходный ряд, то сходится и любой из его остатков, и обратно: из сходимости остатков ряда вытекает сходимость исходного ряда,** то есть отбрасывание конечного числа членов ряда не влияет на вопросы его сходимости или расходимости.

Доказательство: Зафиксируем значение $m$ и обозначим каждую частичную сумму для ряда остатков через $A _k'$:

$$
A_k = a_{m+1} + a_{m+2} + \cdots + a_{m+k}
$$

Представим эту частичную сумму с помощью частичной суммы исходного ряда:

$$
A_m = a_1 + a_2 + \cdots + a_m\qquad A_{m+k} = a_1 + a_2 + \cdots + a_m + a_{m+1} + a_{m+2} + \cdots + a_{m+k}
$$

$$
A_k' = A_{m+k} - A_m\qquad \text{(*)}
$$

Докажем, что в случае сходимости исходного числового ряда сходится и остатки этого ряда. Пусть исходный ряд является сходящимся. Следовательно, существует [[Пределы числовых последовательностей#Определение|конечный предел]] его частичных сумм

$$
\lim_{m\to\infty} A_m = A
$$

где $A$ — конечное число.

Перейдём к пределу в выражении (\*), устремляя $m$ к бесконечности:

$$
\lim_{m\to\infty} A_k' = \lim_{m\to\infty} A_{m+k} - \lim_{m\to\infty}A_m = \lim_{m\to\infty} A_{m+k} - A = A - A = 0
$$

Последовательность частичных сумм ряда остатков является конечным числом, ч.т.д.

Если исходный ряд сходится, то сумма его остатков после $m$-го члена с возрастанием $m$ стремится к нулю.

Для случая расходимости доказательство аналогично.
## Теорема о сходимости произведения ряда на число (№70)
**Если члены [[Числовые ряды. Основные определения#Сходимость числового ряда|сходящегося ряда]] умножить на одно и то же число, то новый ряд тоже будет сходящимся, то его сумма будет равна сумме исходного ряда, умноженной на это число.**

Доказательство:

Рассмотрим исходный сходящийся ряд $a _1 + a _2 + a _ 3 + \cdots + a _n + \cdots$.

Умножим все члены ряда на константу $c$: $ca _1 + ca _2 + ca _3 + \cdots + ca _n + \cdots$.

Пусть существует предел частичных сумм $\lim _{n\to\infty} A _n = A$.

$$
A_n = a_1 + a_2 + a_3 + \cdots + a_n
$$

$$
A_n' = ca_1 + ca_2 + ca_3 + \cdots + ca_n = c(a_1 + a_2 + a_3 + \cdots + a_n) = cA_n
$$

$$
\lim_{n\to\infty} A_n' = \lim_{n\to\infty} cA_n = c\lim_{n\to\infty} A_n = cA
$$

, ч.т.д.
## Теорема о сложении сходящихся числовых рядов (№71)
**[[Числовые ряды. Основные определения#Сходимость числового ряда|Сходящиеся числовые ряды]] можно почленно складывать и вычитать. Получившийся числовой ряд также будет сходящимся.**

Доказательство: Пусть исходные ряды имеют следующий вид:

$$
A = a_1 + a_2 + \cdots + a_n + \cdots\qquad B = b_1 + b_2 + \cdots + b_n + \cdots
$$

Оба эти ряда являются сходящимися.

Сложим эти два ряда:

$$
A + B = (a_1 + b_1) + (a_2 + b_2) + \cdots + (a_n + b_n) + \cdots
$$

$$
(A + B)_n = (a_1 + b_1) + (a_2 + b_2) + \cdots + (a_n + b_n) = (a_1 + \cdots + a_n) + (b_1 + \cdots + b_n) = A_n + B_n
$$

$$
\lim_{n\to\infty} (A + B)_n = \lim_{n\to\infty} (A_n + B_n) = \lim_{n\to\infty} A_n + \lim_{n\to\infty} B_n = A + B
$$

Для разности доказательство аналогично.
## Теорема о сходимости общего члена сходящегося ряда (№72)
**Общий член сходящегося ряда стремится к нулю.**

Доказательство: Пусть ряд $a _1 + a _2 + \cdots + a _n + \cdots$ является сходящимся. Докажем, что его общий член стремится к нулю, то есть $\lim_{n\to\infty} a_n = 0$.

$$
A_n = a_1 + a_2 + \cdots + a_{n-1} + a_n\qquad A_{n-1} a_1 + a_2 + \cdots + a{n-1}\qquad a_n = A_n - A_{n-1}
$$

$$
\lim_{n\to\infty} a_n = \lim_{n\to\infty} (A_n - A_{n-1}) = \lim_{n\to\infty} A_n - \lim_{n\to\infty} A_{n-1} = A - A = 0
$$

, ч.т.д.

Замечание: эта теорема является необходимым условием сходимости числового ряда, но не достаточным, т.е. из сходимости общего члена ряда к нулю не вытекает сходимость самого ряда. В качестве примера можно привести ряды $\sum _{n=1}^\infty \frac{1}{\sqrt n}$ (его расходимость была доказана [[Числовые ряды. Основные определения#Примеры числовых рядов|выше]]) и $\sum _{n=1}^\infty \frac{1}{n}$.
