Положительные ряды удобно сравнивать с заведомо сходящимися или расходящимися рядами.
## Теорема о сравнении членов рядов (№74)
**Пусть есть два положительных ряда**

$$
A = \sum_{n=1}^\infty a_n\qquad B = \sum_{n=1}^\infty b_n
$$

**при этом $a _n \le b _n$ для всех $n$, больших некоторого номера $N$.**

**Тогда из сходимости ряда $B$ вытекает сходимость ряда $A$, а из расходимости ряда $A$ вытекает расходимость ряда $B$.

Доказательство:

Разберём случай, когда $a _n \le b _n$ для всех натуральных $n$. Случай, когда неравенство выполняется, начиная с некоторого номера, не будет влиять на сходимость ряда, так как отбрасывание/добавление конечного числа членов ряда [[Простейшие теоремы числовых рядов#Теорема о сходимости остатков рядов (№69)|не влияет]] на вопросы сходимости/расходимости.

Распишем частичные суммы для двух рядов:

$$
A_n = a_1 + a_2 + \cdots + a_n\qquad B_n = b_1 + b_2 + \cdots + b_n
$$

$$
a_1 \le b_1,\quad a_2 \le b_2, \quad \dots, \quad a_n \le b_n \quad ⇒ A_n \le B_n,\quad \lim_{n\to\infty} A_n \le \lim_{n\to\infty} B_n
$$

Если ряд $B$ сходится, то существует конечный предел его частичных сумм $\lim _{n\to\infty} B _n$. Если предел частичных сумм $\lim _{n\to\infty} A _n$ не превосходит конечное значение, то он тоже будет являться конечным значением, следовательно, ряд $A$ тоже будет сходиться.

Если ряд $A$ расходится, то конечного значения предела $\lim_{n\to\infty} A_n$ не существует. Так как $\lim_{n\to\infty} B_n$ превосходит предыдущий предел, то конечного значения для этого предела тоже не существует, следовательно, ряд $B$ тоже будет расходиться.
## Теорема о сравнении отношений членов рядов (№75)
**Если, начиная с некоторого номера $N$, для всех $n \ge N$ выполняется неравенство $\frac{a _{n+1}}{a _n} \le \frac{b _{n+1}}{b _n}$, то из сходимости ряда $B$ вытекает сходимость ряда $A$, из расходимости ряда $A$ вытекает расходимость ряда $B$.

Доказательство:

Введём обозначение:

$$
q_k = \frac{a_{k}}{a_{k-1}}\qquad r_k = \frac{b_k}{b_{k-1}}
$$

Выразим частичные суммы:

$$
A_n = a_1 + q_2a_1 + q_2q_3a_1 + \cdots + q_2\dots q_na_1\qquad B_n = b_1 + r_2b_1 + r_2r_3b_1 + \cdots + r_2\dots r_nb_1
$$

$$
q_2 \le r_2\quad q_3 \le r_3\quad \dots \quad q_n \le r_n
$$

, следовательно начиная с определённого номера, возможны два случая:
- $q _k \le r _k < 1$: члены ряда $A$ окажутся меньше членов ряда $B$, при этом суммы ряда сходятся, следовательно по предыдущей теореме ряд $A$ сходится при сходимости ряда $B$.
- $1 < q _k \le r _k$: члены ряда $A$ окажутся меньше членов ряда $B$, при этом суммы ряда расходятся, следовательно по предыдущей теореме ряд $B$ расходится при расходимости ряда $A$.
